# Handing it in

The Deskly repo you received is read only. Do not push to it.

1. Create your own **private** GitHub repo from it. Use "Use this template", or clone it and push to a new private repo.
2. Build there.
3. When you are done, invite **alex-overcyai** on GitHub to your private repo for review.
4. Send us a message with these four things:
   - your repo
   - your live URL
   - the platform admin login
   - anything we should know first: what is done, what you cut and why, and where to look first

You do not have to finish everything within the 5 to 7 days. Send what you have at the end of the window.
